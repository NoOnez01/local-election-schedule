# ระบบสร้างตารางควบคุมการจัดให้มีการเลือกตั้ง

เว็บสำหรับกำหนดวันเลือกตั้งท้องถิ่น คำนวณกำหนดการ และพิมพ์ตารางของผู้บริหารท้องถิ่นกับสมาชิกสภาท้องถิ่นรวมกัน

## ใช้งาน

- เลือกตำแหน่ง ประเภท อปท. จังหวัด อำเภอ และชื่อ อปท.
- กด **กดเพื่อเพิ่ม** เพื่อเพิ่มแถวสมาชิกสภาท้องถิ่น โดยข้อมูลตำแหน่งด้านบนยังคงอยู่
- เลือกเขตเฉพาะหรือทุกเขต แล้วกดพิมพ์เพื่อรวมตารางของทุกตำแหน่ง
- จำนวนเขต อบต. ใช้จำนวนหมู่บ้านในตำบลจากชุดข้อมูล กชช.2ค ของกรมการพัฒนาชุมชน ส่วนจำนวนเขต อบจ. ใช้ข้อมูล กกต. สำหรับการเลือกตั้งวันที่ 1 กุมภาพันธ์ 2568
- การตั้งค่าและข้อมูลที่กรอกบันทึกในเบราว์เซอร์ของผู้ใช้งาน

## เปิดเว็บในเครื่อง

เป็นเว็บ HTML/CSS/JavaScript ที่ไม่ต้องติดตั้งแพ็กเกจหรือ build

```sh
python -m http.server 8765
```

เปิด `http://localhost:8765/`

## ตรวจสอบ

ใช้ Node.js รุ่นที่รองรับ `node:test`

```sh
node --test tools/zone-counts.test.js
```

## ข้อมูลจำนวนเขต

- `data/village-counts.js`: จำนวนหมู่บ้านรายตำบลจาก กชช.2ค ครอบคลุมพื้นที่ชนบทนอกเขตเทศบาล
- `data/pao-zones-ect-2568.csv`: จำนวนเขต อบจ. ของ 76 จังหวัด รวม 2,316 เขต จากรายงาน [27 ปี กกต. หน้า 62–63](https://www.ect.go.th/mini/web-upload/38x012f0575ae60054c957e56c3d727e971/202506/m_news/2335/52672/file_download/7c0e2f915e58f7d844bce746852d5490.pdf)
- `data/pao-zones.js`: ข้อมูลสำหรับเว็บและรายละเอียดแหล่งที่มา

สร้างข้อมูลจำนวนเขต อบจ. ใหม่โดยคงข้อมูลหมู่บ้านเดิม:

```sh
node tools/build-zone-data.js - data/pao-zones-ect-2568.csv
```
